## Tagsonian
Tagsonian is an NFC reader / writer, tag decoder, tag translator, tag format editor, and more.  It'll grow over time into a full suite of NFC and 3d printing tools, a filament library and database, and much more.  While it's still in an early beta, I've been using internally it for RFID operations already. It's cost-free, ad-free, setup-free, and data collection free.

## Main Features
- Reads multiple RFID tag standards including OpenTag3D V2.x, OpenSpool V1, and OpenPrintTag V1.
- Supports ACR122U and compatible readers, more to be added.
- Built-in chip specs for NTAG, ST25TN01K, and ST25TN02K NFC. The app knows what will fit and what is supported by what standard.
- Fully parses and translates the information to a readable format.
- Writes directly to RFID tags in the OpenTag3D v2.x standard.
- Writes to multiple JSON and other tag formats including NFC Tools Desktop JSON.
- Imports JSON tag data from files.
- Translates tag data between tag standards.
- Features a raw data inspector that allows viewing, copying (just Hex values or Hex + summary) to clipboard, and saving raw data to raw text files.
- JSON based tag schema / standard viewer and editor: Take a standard layout and clone it. Official standards can't be changed locally, but they can be cloned to make modified schemas. These schemas can be used within the app to produce in-house tag schemas that can be translated to and from other schemas / standards.

## How to Use It
Tagsonian is a self-contained app that doesn't need an setup or installation. You can place it anywhere on your PC and it'll run.
Grab the beta release from here the repo: https://github.com/MadSciSlack/Tagsonian/releases/download/V0.20-B0010/Tagsonian.exe
Just plug in your ACR122U reader and launch the EXE. The basics are super easy to operate, but there's a lot more capability for advanced users.
